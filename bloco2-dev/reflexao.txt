# ATIVIDADE 5 — O shell como JCL moderno

# O slide da genealogia mostrou que o JCL usava comandos como
# // ASSIGN SYS004,TAPE para associar um trabalho a um dispositivo.
# No shell moderno, qual mecanismo cumpre papel equivalente?
# Dê um exemplo concreto do que você usou nesta atividade.

Resposta:
No shell moderno, o mecanismo equivalente é o redirecionamento de entrada e saída e o uso de arquivos/dispositivos representados no sistema. Um exemplo usado na atividade foi:

strace echo "ola" 2>&1 | grep write

Nesse comando, o "2>&1" redireciona a saída de erro para a saída padrão, funcionando de forma parecida com a associação de dispositivos feita pelo JCL.

# ATIVIDADE 6 — Make

# 1. O monitor histórico verificava a conclusão de cada job antes
#    de despachar o próximo. No make, qual mecanismo cumpre esse
#    papel? Como o make sabe que não precisa recompilar um arquivo
#    que não mudou?

Resposta 1:
O make utiliza dependências e comparação de datas de modificação dos arquivos. Ele verifica se algum arquivo-fonte foi alterado depois do arquivo compilado e somente recompila quando detecta mudanças necessárias.


# 2. O monitor unificava "supervisor, carregador e rotinas de I/O
#    sob uma interface textual". O que o Makefile unifica no fluxo
#    de desenvolvimento moderno?

Resposta 2:
O Makefile unifica tarefas do desenvolvimento como compilação, ligação, execução de comandos e organização das dependências do projeto. Ele automatiza várias etapas do processo em uma única interface de comandos.
