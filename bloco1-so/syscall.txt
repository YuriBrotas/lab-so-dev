# PARTE C — Questões de síntese

# 1. A apresentação afirma que "instruções de I/O são privilegiadas".
#    Como um programa de usuário consegue fazer I/O sem executar
#    instruções privilegiadas diretamente? (mínimo 2 frases)

Resposta 1:
O programa de usuário utiliza chamadas de sistema, como write(), para solicitar operações de entrada e saída ao kernel. O kernel executa as instruções privilegiadas em modo kernel e depois retorna o resultado para o programa.


# 2. Compare write(fd, buffer, tamanho) com o "programa de canal"
#    da apresentação: o que os dois têm em comum em termos de
#    responsabilidades?

Resposta 2:
Os dois servem para informar ao sistema quais dados devem ser enviados e para onde eles devem ir. Tanto o write() quanto o programa de canal organizam a comunicação entre o software e o dispositivo de hardware.
